# 📱 Inwentura - Przewodnik Szybki Start

## 🎯 Nowe funkcje offline

Twoja aplikacja Inwentura została ulepszona o **zaawansowane funkcje offline**!

### ✨ Co nowego?

- 💾 **Dane nie znikają** - inwentarz jest automatycznie zapisywany
- 🌐 **Działa offline** - pełna funkcjonalność bez internetu  
- 🔄 **Automatyczna synchronizacja** - dane są bezpieczne
- 📊 **Status połączenia** - zawsze wiesz czy jesteś online

## 🚀 Jak korzystać

### 1. Sprawdź status połączenia
W prawym górnym rogu znajdziesz wskaźnik:
- 🟢 **Online** - masz internet
- 🔴 **Offline** - brak internetu (ale aplikacja działa!)

### 2. Dodawaj produkty jak zwykle
- Wprowadź nazwę produktu
- Ustaw wagę i jednostkę
- Kliknij "Dodaj do inwentarza"
- **Dane są automatycznie zapisywane!**

### 3. Praca bez internetu
Gdy stracisz połączenie:
- ✅ Możesz dodawać nowe produkty
- ✅ Możesz usuwać elementy
- ✅ Możesz przeglądać inwentarz
- ✅ Możesz eksportować dane (CSV/JSON)

### 4. Synchronizacja
- Kliknij przycisk **"Sync"** aby wymusić synchronizację
- Sprawdź czas ostatniej synchronizacji pod statusem

## 🔧 Przydatne funkcje

### Auto-zapis
- Każda zmiana jest automatycznie zapisywana
- Sprawdź czas ostatniego zapisu pod tytułem

### Eksport offline
- Przyciski **CSV** i **JSON** działają bez internetu
- Pobierz swoje dane w każdej chwili

### Czyszczenie danych
- Przycisk **"Wyczyść"** usuwa wszystkie dane
- **Uwaga**: tej operacji nie można cofnąć!

## 🆘 Rozwiązywanie problemów

### Problem: Dane zniknęły
**Rozwiązanie**: Sprawdź czy nie wylogowałeś się przypadkowo. Dane są czyszczone przy wylogowaniu.

### Problem: Aplikacja działa wolno
**Rozwiązanie**: Odśwież stronę. Dane zostaną zachowane.

### Problem: Nie mogę się zsynchronizować
**Rozwiązanie**: 
1. Sprawdź połączenie internetowe
2. Kliknij przycisk "Sync"
3. Poczekaj na zakończenie synchronizacji

## 💡 Wskazówki

### ✅ Dobre praktyki
- Regularnie sprawdzaj status połączenia
- Pozwól na synchronizację gdy masz internet
- Nie zamykaj aplikacji podczas synchronizacji

### ⚠️ Uwagi
- Dane są przechowywane tylko w tej przeglądarce
- Wylogowanie usuwa wszystkie lokalne dane
- Eksport danych to dobry sposób na kopię zapasową
